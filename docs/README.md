## Conventions

- Documents here capture **knowledge** (what was learned), not tasks (what to do)
- Task-specific investigation notes belong in issue descriptions (`br update <id> --description`)
- Repeatable procedures belong in `workflows/`
- Keep documents focused — one topic per file
